MCP, answered.

MCP is the open standard assistants like Claude and Cursor use to call external tools. Activepieces gives your project one server that exposes 760+ apps to your AI as tools.

Most MCP servers cover one app. Activepieces gives you a single URL that exposes every piece you connect, so your AI calls actions across all of them through one connection.

Enable the server under Settings → MCP Server, copy the URL, and paste it into your client config, such as ~/.cursor/mcp.json. It authenticates over OAuth on first use.

Yes. Activepieces has an MIT-licensed core and is free to start, and the MCP server is included on every plan, including the free cloud tier and any self-hosted deployment.

Connections use OAuth2 with limited scopes and credentials are stored under 256-bit encryption, with no API to retrieve them, so an agent gets scoped access rather than your keys.

Yes. Activepieces is fully self-hostable, the MCP server included, so your connections and data stay in your own environment, at your host root or behind a reverse-proxy subpath.
