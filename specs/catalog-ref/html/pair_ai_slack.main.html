What you can build with AI and Slack

A few flows teams run between AI and Slack. Use one as a starting point, or build your own from scratch.

  • New Public Message Posted Anywhere in Slack creates Ask AI in AI

    Triggers when a new message is posted to any channel.

  • New Public Message Posted Anywhere in Slack creates Summarize Text in AI

    Triggers when a new message is posted to any channel.

  • New Public Message Posted Anywhere in Slack creates Generate Image in AI

    Triggers when a new message is posted to any channel.

  • New Message Posted to Channel in Slack creates Ask AI in AI

    Triggers when a new message is posted to a specific #channel you choose.
